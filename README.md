# .github

This is the [Nomasign GitHub organisation profile](https://github.com/Nomasign) repository.

The `profile/README.md` file renders as the public-facing organisation overview at [github.com/Nomasign](https://github.com/Nomasign).

## Structure

```
profile/
  README.md   ← Organisation profile (visible on GitHub)
  logo.png    ← NomaSign logo used in the profile
```

## Editing

Changes to `profile/README.md` are live on GitHub as soon as they're pushed to `main`.
